# EchoMind — Memory Reconstruction UI Prototype

This is a small React + Vite prototype for an AI-powered multimedia memory reconstruction app focused on accessibility and elderly-friendly design.

Quick start:

```bash
npm install
npm run dev
```

Notes:
- Uses mock data in `src/mock/data.js` and simulated AI responses.
- Designed for easy replacement of mock services with real backend AI APIs (face recognition, speech-to-text, TTS, etc.).
- Large buttons, high-contrast, and simplified layouts prioritize usability for older adults.
